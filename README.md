## Project 1: Evaluating AI Responses

### Objective
To practise assessing AI-generated answers for accuracy, relevance, clarity, and completeness.

### Method
1. Read a question and an AI-generated response.
2. Check whether the response answers the question correctly.
3. Identify factual errors, unsupported claims, or missing information.
4. Explain the reasoning behind the evaluation.
5. Provide a corrected answer where necessary.

### Project Status
Independent practice project.

## Project 2: Text Classification

### Objective
To practise categorising text according to clearly defined instructions.

### Method
1. Read the supplied text.
2. Identify the relevant category.
3. Apply the classification rules consistently.
4. Check the result for accuracy.

### Project Status
Independent practice project.
